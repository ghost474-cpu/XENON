Installation Tutorial

Manual Installation

Download the project folder and extract the ZIP file to a dedicated location on your computer.

Open Google Chrome, navigate to chrome://extensions, and enable "Developer mode" in the top right corner.

Click the "Load unpacked" button and select the extracted folder. Congratulations! Xenon is now your new home screen.
